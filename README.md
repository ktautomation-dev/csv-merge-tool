# CSV Merge Tool

複数のCSVファイルを安全に1つへ結合するPythonツールです。

同じフォルダ内のCSVを自動で読み込み、ヘッダーを重複させずに結合します。  
列構成が異なるCSVを検知した場合は処理を中止し、不完全な出力ファイルを残さないようにしています。

## 主な機能

- 複数CSVの一括結合
- ヘッダー重複の防止
- 列構成の自動チェック
- 空CSVのスキップ
- エラー発生時の安全停止
- 出力ファイルの自動生成
- 日時付きファイル名
- 処理件数の表示
- 処理時間の計測
- UTF-8 BOM付きCSV出力

## 実行時のフォルダ構成

```text
CSV_Merge_Tool
├── input
│   ├── 売上_20260801.csv
│   ├── 売上_20260802.csv
│   └── 売上_20260803.csv
├── output
└── merge_csv.py
```

サンプルCSVとソースコードは、このリポジトリ内の `sample`・`src` フォルダに掲載しています。

## 使い方

### 1. フォルダを準備

以下の構成で `input`・`output` フォルダを作成し、`merge_csv.py` を配置します。

```text
CSV_Merge_Tool
├── input
├── output
└── merge_csv.py
```

### 2. CSVファイルを配置

結合したいCSVファイルを `input` フォルダに入れます。

```text
input
├── 売上_20260801.csv
├── 売上_20260802.csv
└── 売上_20260803.csv
```

### 3. プログラムを実行

ターミナルで次のコマンドを実行します。

```powershell
py merge_csv.py
```

### 4. 結合結果を確認

処理が完了すると、`output` フォルダに日時付きのCSVファイルが作成されます。

```text
売上結合_20260808_142210.csv
```

## サンプルデータ

動作確認用のCSVファイルを `sample` フォルダに掲載しています。

3つのサンプルCSVを結合すると、ヘッダーを除いて**合計6件**のデータが1つのCSVにまとめられます。

---

## エラー処理

CSVファイルごとに列構成をチェックします。

例えば、通常のCSVが

```text
日付,担当者,商品,数量,単価
```

という構成なのに、異なる列構成のCSVが含まれていた場合は処理を中止します。

```text
処理を中止しました。
列構成が異なります: 売上_エラーテスト.csv
```

エラー発生時には、不完全な出力ファイルを残さないようにしています。
